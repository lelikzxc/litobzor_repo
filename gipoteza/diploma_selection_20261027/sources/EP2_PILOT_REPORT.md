# EP2: минимальные разделители, новый отдельный опыт

26 октября 2026 года. **Полный замороженный gate — FAIL.** Метод
превзошёл все восемь внешних сильных контролей, но не достиг заранее
требуемых +2 п.п. относительно собственной невзвешенной абляции.
Критерий после результата не менялся. CNN не обучалась.

Это отдельный алгоритм и новый TEST после EP1 FAIL; результаты EP1
не переименованы и не пересмотрены.

выигрыш положителен, но существенно меньше заданной величины.

## Как выбирались параметры

До новых TEST counts сформирована отдельная VAL из прежних sourceframes
6/7. После исключения TRAIN-совпадений и группировки H/V-повторов
доступны **94 геометрии каждого класса**, всего188. Выбор по SHA256 ID,
без использования scores. VAL содержит 12 032 count-реализации.

| Кандидат основного семейства | VAL Macro-F1, % |
|---|---:|
| Невзвешенный EP2 | 43.600 |
| Weighted EP2 tau0.5 | **44.367** |
| Weighted EP2 tau1 | 44.321 |
| Weighted EP2 tau2 | 44.172 |

Каждый prior-зависимый контроль независимо получил тот же tau-grid
[0.5,1,2] и выбрал температуру по своей VAL-метрике. Выбор сохранён в
[VAL_SELECTION_BEFORE_TEST.json](VAL_SELECTION_BEFORE_TEST.json) **до
генерации TEST counts**. После TEST ни основной вариант, ни контролы
не менялись. Все VAL-калибраторы и все TEST-исходы сохранены.

Hochberg добавлен до начала запуска и до каких-либо EP2 scores. Hommel
не реализован: statsmodels отсутствует; необязательная просьба о нём
поступила уже после завершения запуска. Это дополнительный возможный
контроль будущего отдельного опыта, не основание менять данный gate.

## TEST и измерительная модель

Взяты **256 геометрий** (128 каждого класса), зарезервированных до EP1
исходов как future holdout. Они не входили в EP1 пилот и не совпадают
с TRAIN/VAL по точным H/V-образам. Это новые 6×6-квадранты исходных
бинарных SEM-масок; исходные SEM-интенсивности не выдаются за counts.

Созданы новые независимые integer Poisson наблюдения A/B с известными
двумя интенсивностями, четырьмя дозами и16повторами: **16 384** наблюдения
на256геометриях. Среди128отрицательных **46** становятся связанными
после добавления одного пикселя. Поэтому проверка включает почти
соединённые отрицательные структуры.

Роль A — только аналитическое предложение q_A и выбор контрольных
путей/коридоров. Роль B — статистическое свидетельство. Температуры
выбраны на VAL; TEST-labels не участвуют в весах. Сегментационная
CNN в этом опыте отсутствует.

## Полное семейство и корректность реализации

- Для6×6 перечислены **все4286** включительно минимальных разделителей,
  размеры **6–14**. Ни один cut не отсеивался по A/B или истинной маске.
- Для4×4 получены78разделителей. Совпадение с минимальными cut среди
  всех65 536подмножеств точное. На каждой маске4×4 выполнено «нет
  foreground LR-связи ⇔ имеется полностью background cut»; ошибок0.
- Для каждого6×6cut проверены разделение и необходимость каждой
  вершины: **36 836** удалений вершин без нарушения проверки.
- Проверены Holm, weighted Holm, Hochberg и конечная4-связность по
  буквальным алгоритмам и fixtures. Unknown-Macro-F1 сверена со sklearn.
- Численно проверено теоретическое включение Bonferroni-сертификатов
  в невзвешенную EP2. Оно следует из max|K|=14 и2|K|<36, а не из
  удачно выбранного TEST.
- Полные/локальные SLRT опираются на отдельно проверенный min-cut
  oracle EP1; все методы и температуры завершены, незавершённых
  обязательных контролей нет.

Подробности: [RUN_VERIFICATION.json](RUN_VERIFICATION.json),
[VERIFICATION.json](VERIFICATION.json). Весь EP2 запуск с подготовкой
геометрий, VAL-подбором, TEST, всеми методами и bootstrap занял
**28.85секунды**, меньше600секунд. Код и протокол готовились ранее.
Хэши замороженных файлов после результата проверены и не изменились.

## Ошибки и область гарантии

Weighted EP2 не дала ни одного ложного конечного подтверждения соединения
на8192отрицательных count-реализациях. Для невзвешенной EP2 был один
такой случай при d=2. Полные числа сырых сертификатов, конфликтов и
решений сохранены по каждой дозе в [RESULT.json](RESULT.json).

Общий отрицательный сертификат иногда ошибался на положительных
геометриях. Противоречие с положительным сертификатом переводилось в
unknown, поэтому число конечных ложных разрывов различается между
методами при одинаковом отрицательном сертификате. Эти случаи не
удалялись и участвуют в Macro-F1.

Гарантия относится к известной независимой Poisson-модели без PSF и
к точно определённому бинарному классу. Кропы и шумовые повторы не
равны независимым wafer/lot; bootstrap описывает конечную геометрическую
выборку одного IC-источника. Здесь нет проверки неизвестных фоновых
интенсивностей, размытия, физической проводимости материала или новой
производственной калибровки.

## Решение

Есть предварительное свидетельство полезности **теста минимальных
разделителей** против сильных внешних решений. Дополнительная польза
аналитических image-весов положительна, но не достигла заранее
требуемых2п.п. Полный результат остаётся **FAIL**, успешная гипотеза о
пользе обучаемой CNN из этого опыта не следует. Переопределять критерий
на этой же TEST-выборке нельзя.
