# Зафиксированная модель CNN для металлизации M2

Зафиксировано 3 ноября 2026 года. Основной вариант модели — `GroupCNN` с шестью базовыми признаками и четырьмя ориентациями C4. Фиксация сохраняет уже проверенные архитектуру, веса, условия обучения, пороги и результаты. Новых обучений или предсказаний при фиксации не выполняется.

## Задача

По SEM-фрагменту 12×12 пикселей восстановить бинарную маску металлизации M2 и по этой маске определить один из девяти геометрических классов. Для каждого направления — слева направо и сверху вниз — прежнее резисторно-геометрическое правило задаёт три состояния. Совместный класс равен `y = 3*sLR + sTB`.

Эти классы вычислены из SVG-масок. Они не являются экспертной разметкой типов производственных дефектов, результатами электрических измерений или оценкой выхода годных изделий.

Данные: открытый набор Rothaug et al., [A Real-World Metal-Layer SEM Image Dataset with Partial Labels](https://doi.org/10.17617/3.HY5SYN), лицензия CC BY 4.0. Используются SEM-изображения слоя M2 одной физической ИС. Нативные фрагменты 48×48 уменьшаются усреднением 4×4; нормализация входа: `5*(X12 - 0.2)`, `float32`, форма `[N, 1, 12, 12]`.

## Архитектура

```text
SEM 12×12
 → lifting Conv3×3: 6 признаков × 4 ориентации → GELU
 → C4 group Conv3×3, dilation 2 → GELU
 → C4 group Conv3×3, dilation 4 → GELU
 → среднее по четырём ориентациям
 → Conv1×1: 6 → 1
 → вероятность металла → пороговая маска → фиксированное правило класса
```

Модель имеет 2 671 независимый обучаемый параметр. После материализации связанных фильтров обычные свёртки содержат 10 681 коэффициент, связанных исходными весами. Их число нельзя представлять как число независимых обучаемых параметров. Стоимость одного изображения — 1 527 552 MAC.

Контроль `Plain12 C4` содержит 2 749 параметров и требует 1 562 112 MAC на изображение, включая четыре поворота и усреднение вероятностей. Он обучается через этот же четырёхвидовый маршрут. Различие параметров и MAC с GroupCNN меньше 3%.

Внутреннее связывание повёрнутых свёрточных фильтров исследуется как изменение модели. Используется известная конструкция [групповых эквивариантных CNN](https://proceedings.mlr.press/v48/cohenc16.html); изобретение самой C4-свёртки и готовая публикационная новизна не заявляются.

## Обучение и семейство весов

Сохранены все шесть проверенных состояний GroupCNN: бюджеты 18 и 27 масок × seed 5701, 5721, 5757. Выбор лучшего seed по результатам не выполняется. Отдельно сохранены исходные контрольные модели, необходимые для воспроизведения сравнения.

- TRAIN: кадры 0–5; прежняя VAL: кадры 6–7, 695 фрагментов.
- Бюджет полной разметки: 18 или 27 масок, по 2 или 3 на класс.
- Дополнительный надзор: 1 152 примера только с классовой меткой; их маски в обучение не поступают.
- AdamW, 2 000 обновлений, скорость обучения 0,0005, weight decay 0,0001.
- Первые 400 обновлений: BCE по полным маскам; следующие 1 600: BCE и прежний геометрический компонент с весом 1.
- Dense batch 8 и weak batch 8, одинаковые последовательности выборки для сравниваемых моделей.
- Порог итоговой маски выбирается на прежней VAL по фиксированной сетке 0,10…0,90 с шагом 0,01. Все пороги зафиксированы до закрытой проверки.

Геометрический компонент является общим вспомогательным условием обучения. Самостоятельный эффект архитектуры при его отключении проверяется отдельной абляцией; текущий подтверждённый результат относится к полному зафиксированному режиму.

## Закрытая проверка

С неизменёнными весами и прежними VAL-порогами проверены 4 096 фрагментов из 16 новых кадров той же ИС. Модели оценены по трём seed и двум бюджетам. Числа ниже — среднее качества отдельных моделей, не качество ансамбля.

| Показатель | GroupCNN | Plain12 C4 |
|---|---:|---:|
| Macro-F1 девяти классов, % | 75,895816 | 74,041449 |
| IoU маски металла, % | 86,546016 | 85,355854 |
| Независимые обучаемые параметры | 2 671 | 2 749 |
| MAC / изображение | 1 527 552 | 1 562 112 |

Прирост Macro-F1 равен +1,854366 п.п.; центральный 97,5%-й интервал парного crossed-bootstrap по seed и кадрам составляет [+0,352767; +3,695357] п.п. Использовано 10 000 повторов и поправка на два заранее определённых сравнения. Основной критерий A пройден; независимый аудит данных — 17/17, итогового результата — 13/13.

Практический порог +0,5 п.п. относится к наблюдаемой точечной оценке. Нижняя граница интервала больше нуля, но меньше +0,5 п.п.; результат не доказывает минимальный популяционный выигрыш ≥0,5 п.п.

Отдельное сравнение с более крупной `Plain24 C4`: её Macro-F1 равен 74,912671%, разность с GroupCNN — +0,983144 п.п., 97,5%-й интервал [−1,327855; +3,750616] п.п. Заранее установленная статистическая граница неухудшения −0,5 п.п. не пройдена. Вторичная цель B не подтверждена.

## Использование и границы результата

Для примера загрузки указан `group6_b27_s5701.pt`. Это заранее существовавший seed первого этапа, а не выбранный по закрытому качеству победитель. Все шесть весов имеют одинаковый статус внутри соответствующего бюджета; рабочее сравнение усредняет их индивидуальные метрики.

```python
from pathlib import Path
import sys
import torch

run = Path('gipoteza/sem_arch_groupcnn_20261102').resolve()
sys.path.insert(0, str(run))
from model import GroupCNN

path = (run / 'trials/groupcnn_screen_s5701_metadata_recovery_27b9055b42'
        / 'models/group6_b27_s5701.pt')
saved = torch.load(path, map_location='cpu', weights_only=True)
net = GroupCNN().eval()
net.load_state_dict(saved['model'])
deployed = net.deploy()
# X12: float32 [N, 1, 12, 12].
# probability = deployed(5 * (X12 - 0.2)).sigmoid()
# Для этого состояния прежний primary_fine_threshold берётся
# из MODEL_LOCK.json; запрещено подбирать его на закрытой выборке.
```

Закрытая проверка установила преимущество относительно конкретного контроля при близком бюджете на новых кадрах одной ИС. Перенос на другие ИС, другие слои, экспертные типы дефектов и производственные условия этим экспериментом не проверены. Измеренная задержка прежнего эксперимента включает CNN-маршрут, но не общий CPU-расчёт геометрического класса; это не полное время приложения.

Прежняя VAL многократно использовалась в разработке. Последующие абляции на ней имеют статус анализа компонентов. Закрытые 16 кадров нельзя использовать для выбора новых весов, архитектуры или порогов и затем повторно называть независимым подтверждением.
