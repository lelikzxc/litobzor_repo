# Фиксация основной CNN — 3 ноября 2026 года

Основной вариант ВКР сохранён как семейство шести состояний `GroupCNN`: два бюджета масок и три seed. Сохранённый режим обучения включает общий прежний геометрический компонент; его отключение исследуется отдельным экспериментом.

Архитектура и результаты описаны в [MODEL_CARD.md](MODEL_CARD.md). Список 275 зафиксированных файлов с SHA-256 находится в [FROZEN_MODEL.json](FROZEN_MODEL.json). Реестр включает 18 финальных весов сравниваемых моделей, 18 начальных состояний и 6 материализованных GroupCNN, а также исходный код, разбиение данных, пороги и результаты двух этапов. Файлы прежних экспериментов не изменены; здесь добавлен реестр их точных версий.

Проверка всех файлов из корня репозитория:

```sh
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -B \
  gipoteza/sem_model_freeze_20261103/freeze.py --verify
```

Команда читает байты и записывает только новый [VERIFY.json](VERIFY.json) в этой папке. PyTorch, обучение и обработка изображений не запускаются. Повторная генерация без `--verify` допускается только при побайтовом совпадении существующего реестра; новый изменённый реестр поверх прежнего не записывается.

Основная закрытая проверка A пройдена: +1,854366 п.п. Macro-F1 относительно обычной CNN с близкими параметрами и MAC. Вторичное статистическое неухудшение относительно полной CNN не подтверждено. Выбор лучшего seed по закрытой выборке не выполнялся. Поясняющие документы в этой папке не входят в научный реестр и могут дополняться без изменения зафиксированных весов или результатов.
