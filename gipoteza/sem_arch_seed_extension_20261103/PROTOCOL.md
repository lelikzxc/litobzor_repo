# Репликация по двум дополнительным инициализациям

Заранее выбраны seed 5801 и 5821. Для каждого обучаются Group6 и Untied24; вместе с прежними 5701, 5721, 5757 получается пять пар. Все четыре новых обучения сохраняются независимо от результата. Это проверка устойчивости к инициализации на уже известной тестовой выборке, не новый независимый тест и не новая когорта.

Для каждого seed Group6 создаётся на CPU через прежний `make_model('group6', seed)`. Untied24 получает развёртку именно начального Group6; все 10681 параметр затем обучаются независимо. Начальные функции совпадают с допуском 1e-6. Group6 имеет 2671 независимый параметр. Обе модели выполняют один проход и 1527552 MAC на участок. Различие в числе свободных параметров и геометрии оптимизации сохраняется.

Обучающие данные, подвыборка 27 плотных масок и 1152 слабых меток, нормировка `5*(X-.2)`, AdamW, 2000 обновлений, lr=0.0005, weight_decay=0.0001, первые 400 обновлений с BCE и последующие 1600 с прежним BCE+geometry_loss весом 1 сохраняются. Размеры минибатчей 8+8; генератор NumPy seed+1000 сначала выбирает плотный, затем слабый минибатч на каждом шаге, включая прогрев. Слабые маски не читаются. Сохраняются начальные/конечные веса и градиентные пробы до шагов 1 и 401. Гиперпараметры и архитектуры не выбираются по результатам.

Для каждого нового состояния порог выбирается только по тем же 512 классам из 32 старых DEV-кадров, индексы которых зафиксированы в FINAL_CALIBRATION.json предыдущего закрытого исследования. Перебор 81 порога 0.10..0.90 с шагом 0.01: максимальный Macro-F1, затем минимальное целочисленное расстояние до 0.50, затем меньший порог. Маски/IoU не участвуют в выборе порога. Сначала фиксируются все четыре порога, затем вычисляются новые тестовые предсказания на прежних 6144 участках 24 кадров. Тест уже известен; процедура не заявляется как новая независимая проверка.

Основные показатели: Macro-F1 девяти классов, средняя по кадрам пиксельная AP, средняя по участкам IoU. Показываются новые две пары отдельно, прежние три пары отдельно и все пять вместе. Старые массивы предсказаний копируются без пересчёта; для узкой Plain12 новых обучений нет. Результат новых seed нельзя скрыть положительным средним всех пяти.

Описательная проверка новых двух пар: средняя разница F1 >=0.005, средняя разница AP >0, каждый seed F1 >=-0.01, средняя разница IoU >=-0.002. Для всех пяти также рассчитываются прежние составные критерии с положительными нижними границами интервалов AP/F1. Интервалы получаются 10000 парными перекрёстными пересэмплированиями пяти seed и 24 кадров, seed генератора 202611035. В каждом повторе F1 сначала пересчитывается по сумме матриц выбранных кадров отдельно для каждого выбранного seed, затем усредняется по seed. AP усредняется по выбранным кадрам и seed. Одни индексы используются для обеих моделей и обоих показателей; центральные 97.5% интервалы дают поправку на два исхода. Это приближённые описательные интервалы репликации, не новая проверка на независимых данных. Порог 0.5 — только дополнительная диагностика, не основание менять основной результат.

Исходный закрытый результат остаётся неизменным. Новизна оператора, перенос на другую ИС, физические электрические дефекты и универсальное превосходство по всем порогам этой проверкой не устанавливаются.
