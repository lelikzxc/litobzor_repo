# Качество масочных вероятностей и перенос калибровки между кадрами

3 ноября 2026 года. Две диагностические проверки на ранее просмотренных данных
разработки. Протокол и вычислительная процедура фиксируются до новых расчётов.
Обучение CNN, изменение весов, загрузка новых кадров и новый закрытый тест
этим протоколом не предусмотрены. Исторические закрытые результаты сохраняются.

## Модели и данные

Девять фиксированных состояний: GroupCNN, Untied24 single и Plain12 C4 × seed
5701/5721/5757 при бюджете 27 полных масок. Во всех моделях один и тот же прежний
режим дополнительного обучения по 1152 weak-меткам. Group и Untied имеют одинаковые
ширину/MAC и начальную функцию, но 2671 и 10681 свободных параметров. Plain12 C4
имеет 2749 параметров и близкий MAC. Эти различия учитываются в интерпретации.

Основное сравнение — Group−Untied; Group−Plain12 C4 — дополнительное. Все три seed
имеют одинаковый статус, ансамбли и выбор лучшего seed не используются.

Первый набор: прежняя VAL из 695 фрагментов кадров 6/7, только для отдельной
описательной проверки AP по уже сохранённым вероятностям девяти моделей.
Второй набор: объединение EVAL прежней 16-кадровой проверки (4096 фрагментов)
и EVAL следующей 24-кадровой проверки (6144). Получается 40 разных кадров,
10240 фрагментов, по 256 на кадр. Здесь эти ранее оценённые кадры явно имеют
статус DEV. Их результаты не называются новым закрытым подтверждением.

Проверяются неизменность исходных архивов, координат/меток, отсутствие точных
D4-повторов масок и исходных интенсивностей между двумя частями, фиксированные
веса и нормализация 5*(X−0.2). Девять моделей оцениваются одним inference-кодом.
До этого preflight на 17 прежних VAL-примерах сверяет вероятности с архивными
(допуск 1e-5) и маски/классы при 0.5. Код, веса, данные, протокол и конфигурация
связываются SHA-256. Независимый аудит обязателен до расчёта новых предсказаний.

Маска — металл слоя M2 одной ИС. Девять классов вычислены геометрическим правилом
из SVG-масок; это не экспертные типы производственных дефектов и не электрические
измерения. Межчиповый перенос здесь не изучается.

## Проверка 1: качество до бинаризации

Используется non-interpolated average precision (AP), а не площадь трапеций под
PR-кривой. Для каждого кадра и seed все пиксели его 256 фрагментов объединяются;
AP считается по вероятностям металла и бинарной целевой маске. Затем AP
усредняется по 40 кадрам и трём seed. Каждый кадр имеет одинаковый вес.
Фиксируются также значения каждого кадра/seed и доля металла.

Как дополнительная описательная характеристика рассчитывается pooled pixel AP
всего DEV для каждого seed. Для прежней VAL отдельно приводится AP по двум
кадрам и среднее seed. Результаты VAL и 40-кадрового DEV не смешиваются.

AP оценивает ранжирование пикселей металла до выбора порога. Она не является
Macro-F1 девяти классов и не заменяет проверку классификации. Строго монотонное
преобразование оценок не меняет ранжирование; это проверяется на синтетических
данных с отдельной проверкой обработки равных значений.

## Проверка 2: покадровая проверка калибровки

Пять фиксированных fold. Сорок frame ID сортируются по
SHA256('SEM-C4-CALIB-FOLD-20261103/'+decimal_id) и распределяются round-robin.
В каждом fold восемь кадров полностью отложены для оценки, 32 доступны для
калибровки. Кадры и фрагменты оценки не участвуют в выборе порога этого fold.

Бюджет калибровки — ровно 512 классовых меток: 16 фрагментов каждого из 32
кадров. Для каждого кадра берутся первые 16 по
SHA256('SEM-C4-CALIB-ROW-20261103/'+raw_D4_sha256). Маска, класс, архитектура,
seed и вероятность не используются в ранжировании. Выбранные 512 меток одни
и те же для всех моделей и seed данного fold. Отсутствующие классы в этой
фиксированной подвыборке фиксируются, без замены или повторного отбора.

Выбор порога каждой модели/seed: максимум Macro-F1 девяти классов на этих 512
метках из прежней общей сетки 81 значения 0.10…0.90. При равенстве выбирается
ближайший к 0.5, затем меньший порог. IoU в выборе порога не используется,
поэтому дополнительные полные маски для калибровки не требуются. Это новая
заранее заданная процедура, а не переоценка исходных закрытых протоколов.

Выбранный порог применяется ко всем 2048 фрагментам восьми отложенных кадров.
Сохраняются все 81 калибровочных значения, выбранные пороги, индексы калибровки
и оценки, классы/маски/IoU отложенных примеров. Каждый из 10240 примеров ровно
один раз получает out-of-fold предсказание от процедуры, не использовавшей его
кадр для калибровки.

Бюджет 512 относится к одному fold. Между fold метки повторно используются:
объединение всех калибровочных подвыборок содержит 640 уникальных классовых
меток (40×16), общих всем девяти состояниям моделей. Они не суммируются
как 2560 независимых аннотаций и не называются 512 метками на весь опыт.

Основной показатель классификации: Macro-F1 всех OOF-предсказаний отдельно для
каждого seed, затем среднее трёх seed. Confusion разных seed не объединяются.
Отдельно приводятся пять fold-средних Macro-F1, IoU, распределение порогов и
покрытие классов калибровки. Контроли — общий 0.5 и прежние VAL-пороги; они
описательные и не заменяют результат новой покадровой процедуры.

## Интерпретация и заранее заданный ориентир

Обе проверки описательные: DEV уже просмотрен, новых доверительных интервалов,
p-value и статистического подтверждения нет. Миллионы пикселей и перекрывающиеся
фрагменты не считаются независимыми экспериментальными повторениями.

Ориентир для целесообразности БУДУЩЕЙ отдельной закрытой проверки Group−Untied:
все условия одновременно:

- средний по кадрам/seed ΔAP >0;
- средний OOF ΔMacro-F1 ≥+0.5 п.п.;
- средний OOF ΔIoU ≥−0.2 п.п.;
- ΔMacro-F1 каждого fold, усреднённый по seed, ≥−1 п.п.

AP не спасает отрицательную классификацию; фиксированный 0.5, прежние пороги,
выгодный seed или отдельный fold не спасают общий отрицательный исход.
Любой результат сохраняется полностью. Само прохождение ориентира не даёт
модели нового подтверждённого статуса. Следующий закрытый опыт потребует
отдельной фиксации на ещё не использованных кадрах и учёта бюджета калибровки.
