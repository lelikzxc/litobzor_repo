## Скрипты

| Файл | Назначение |
|---|---|
| [core.py](core.py) | Интервальный сертификат, четыре политики, имитатор запросов |
| [prepare.py](prepare.py) | Первые 72 состояния/4032 события, фиксация разбиения и нативной разметки |
| [learning.py](learning.py) | Один общий CNN на политику не создаётся: два seed общей модели, только TRAIN |
| [run_queries.py](run_queries.py) | Трассы четырёх политик при одинаковых бюджетах |
| [evaluate.py](evaluate.py) | Общий CNN+сертификаты, F1 и групповой bootstrap |
| [prepare_extension.py](prepare_extension.py) | Все десять других геометрий, 90 состояний/5040 событий |
| [cost_extension.py](cost_extension.py) | Сравнение стоимости при обязательном точном классе |
| [verify_and_mechanism.py](verify_and_mechanism.py) | Независимые метрики, скрытые входы, неоднозначные примеры |
| [make_figures.py](make_figures.py) | Статические научные графики |

`models/seed17.pt`, `models/seed41.pt` — веса; `queries/` и `cost_extension/`
содержат маски раскрытых блоков, интервалы и конечные классы;
`evaluation/` — все прогнозы и сводка. Исходные прошлые опыты не изменены.

Скрипты подготовки используют неизменяемые пути локальных upstream-архивов.
Это воспроизводимость в текущей рабочей копии, а не самостоятельный пакет
без внешних данных. Для переноса на другую машину нужно перенести открытые
исходные архивы с проверкой хешей и обновить инвентарь путей.

Существующие папки запусков не перезаписываются. `learning.py` и
`run_queries.py` принимают `--out`; для полной новой репликации остальные
этапы требуют согласованной смены путей вывода. Все оптимизации требуют
реального MPS без CPU fallback; CPU достаточен для геометрического анализа.
