# H7: фиксированный первый опыт по достаточности наблюдения

Дата: 25.10.2026. Это новый кандидат, а не переименование H6.2.
Задача изменена явно: классификация **наблюдаемого результата литографии**
по уменьшенному изображению с возможностью запросить отдельные фрагменты
исходного разрешения. Это не прогноз будущего изготовления по одной маске.
Начальный опыт использует идеальные бинарные RI LithoSim, без шума сенсора.

## Проверяемое предположение

При равном бюджете раскрываемых пикселей выбор фрагментов по геометрическим
свидетельствам неопределённого класса повышает Macro-F1 сужений/объединений
относительно выбора по пиксельной неопределённости. Проверяемый механизм:
большинство неопределённых пикселей не меняет физически определённый класс;
важны незавершённые соединения нужной толщины и наличие проектных опор.

Нейросеть служит общим резервным классификатором, а однозначные решения
подтверждаются интервалом допустимых геометрий. Сертификат корректности
проверяется отдельно от сравнительной пользы и не считается новой теоремой
общей интервальной арифметики или доказательством Q1-новизны.

## Данные и разбиение до нового расчёта

Использовать восемь прежних development-геометрий из
`h6_selection_audit_20261025/fresh_combined/INPUTS_FROZEN.json`.
Для каждой — первый рецепт по `(archive, group)` и фиксированные индексы
состояний `[0,5,10,11,16,21,22,27,32]`: три фокуса × три дозы.
Все 56 прежних проектных событий сохраняются; всего 72 состояния/4032 события.
Никакого выбора по новым исходам. Четыре TRAIN и четыре EVALUATION по сортировке
SHA256(`h7/readout-v1/`+geometry), первые четыре TRAIN. Проверить D4/shift
разделение по прежнему допуску и хеши. Это разработческая выборка одного
источника дизайнов; независимым подтверждением новой гипотезы не объявляется.

Вход: точные суммы бинарных пикселей каждого блока 8×8, проектные области
опор/домен, тип события и проектный допуск. Одна операция уточнения открывает
все 64 пикселя выбранного смешанного блока. Уменьшенное изображение уже
предполагается полученным; его аппаратная стоимость не принимается за ноль.
Исходный RI хранится только у имитатора запросов и оценки. Политика выбора
получает агрегаты/раскрытые фрагменты, но не остальные пиксели или эталонный класс.

## Математическая проверка

Из наблюдения строятся маски $P^-\subseteq P\subseteq P^+$.
У пустого/полного блока все пиксели известны; смешанный блок без раскрытия
неизвестен. Области вне проектного домена исключаются одинаково.
Радиус пути $q$ монотонен по включению масок. Для required проверка
$q\ge q_{ref}/2$, для forbidden $q\ge1.5$ выполняется связностью CC8 множества
пикселей с EDT не меньше порога. Наличие обеих опор монотонно; граница
занятости каждой опоры 0.5. Интервалы нарушения обязательно учитывают
отсутствие опор: само gated-нарушение required не монотонно по маске.
Нельзя просто классифицировать две крайние маски и объявить все промежуточные
маски одинаковыми. Аналитические тесты должны покрыть этот контрпример.

## Сравнение

Для всех политик одинаковы начальное наблюдение, набор действий, интервальный
сертификат, общий резервный CNN и максимальное число уточнений.
Бюджеты: 0,8,32,128 блоков из 1024, то есть максимум 0%,0.78125%,3.125%,12.5%
площади локального окна высокого разрешения. Блоки раскрываются пакетами по 8;
при достоверно определённом локальном классе дальнейших запросов нет.

Политики: (1) главный сильный контроль — неоднозначные опоры, затем энтропия
доли foreground в блоке; (2) тот же приоритет опор, затем близость к центру
проектного окна; (3) тот же приоритет опор, затем фиксированный случайный порядок;
(4) предлагаемый вариант — неоднозначные опоры, затем неизвестные участки
оптимистического пути нужной толщины и его окрестности. Без истинного пути на входе.
Случайный порядок имеет фиксированный seed; никакого выбора выигрышного повтора.

CNN предсказывает три локальных класса: норма/нарушение/отсутствие опоры.
Обучается только на TRAIN, seed17/41, одинаков для всех политик. Случайные
маски раскрытия используют лишь TRAIN. Максимум 1200 шагов, checkpoint последнего
шага, без выбора по EVALUATION. При неопределённом сертификате используется
тот же CNN на текущем наблюдении. В итоге все случаи получают ответ; неопределённые
не выбрасываются из F1. Нативный полный расчёт — эталон, не конкурент по стоимости.

## Метрики и решение

Главная оценка: глобальный Macro-F1 двух типов нарушений после OR локальных
решений, с равным весом геометрии, среднее двух seed, бюджет 32 блока.
Дополнительно: локальный трёхклассовый Macro-F1, полнота каждого нарушения,
сертифицированная доля, ошибочные сертификаты, фактическая площадь уточнений,
время алгоритма и кривые по остальным фиксированным бюджетам. Отказ от ответа
не подменяет классификацию. Дубликаты областей разных событий учитываются
повторно в локальной стоимости; экономия полного поля/времени микроскопа не заявляется.

Предварительный положительный сравнительный сигнал: delta>=1 п.п. против
главного контроля и положительная нижняя граница парного группового 95% CI,
без изменения знака по seed. Минимальный фильтр данных: оба нарушения есть
минимум на двух EVALUATION-геометриях; иначе сравнительный вывод недостаточен.
Обязательное инженерное условие — ни одного ошибочного сертификата и точное
совпадение полного раскрытия с прежними метками. Полезный сертификат сам по
себе не подтверждает сравнительную гипотезу. Малый опыт не подтверждает Q1-уровень.

Если бюджет времени/данных не позволяет завершить вычисления, сохранить
частичный статус, не выдавать его за отрицательную или положительную проверку.
Любые изменения — отдельная поправка до нового опыта, исходные попытки сохраняются.
