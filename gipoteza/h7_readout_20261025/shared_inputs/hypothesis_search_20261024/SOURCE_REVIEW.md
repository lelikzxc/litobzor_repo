# Проверка направлений и ближайших источников

Дата поиска: 24 октября 2026 года. Цель — новая проверяемая гипотеза «микроэлектроника + компьютерное зрение + классификация», открытые данные, выполнимый первый опыт на RTX 4060 Laptop 8 ГБ.

Учтены требования `full_wafer_research_context_updated.md`, сохранённая карта `gipoteza/literatura_20261019.md`, отрицательные результаты H5 и SEM/DAFT. Общий контекст предшествует новым опытам, поэтому его исторические статусы не принимаются за текущее состояние экспериментов.

## Выбранный исследовательский вопрос

Предсказывать критические значения параметра литографии для отдельных требуемых и запрещённых геометрических связей и проверять перенос классификации при смене ограничивающего участка. Новизна относится к проверяемой совокупности постановки, надзора, декодирования и переноса. Она не относится к идее технологического окна, монотонной сети, max/min или топологической потере вообще.

## Реальная проверка данных

[TRAIN-аудит](lithosim_audit/README.md) сохраняет воспроизводимый код и найденные ограничения. Открытость ресурса подтверждена фактической загрузкой одного небольшого архива. Отдельно обнаружено разночтение лицензии: [карточка Hugging Face](https://huggingface.co/datasets/grandiflorum/LithoSim) указывает AFL-3.0, [авторский проект](https://dw-hongquan.github.io/LithoSim/) — CC BY-NC 4.0 для данных и Apache 2.0 для кода. Эти обозначения не подменяются одним выдуманным статусом; для распространения производного набора надо сверить актуальные файлы лицензии.

Поиск охватывал semiconductor/wafer/SEM defect classification, lithography hotspot/process window, local constraints, critical dose, monotonic/ordinal/interval-censored learning, maximin/widest-path/MALIS и отдельные пары названий. Использованы первичные статьи, страницы конференций, авторские репозитории и технические патентные тексты. Проверка не исчерпывает мировую литературу; непрочитанные платные методы отмечены явно.
