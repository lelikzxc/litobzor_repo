# Описательный разбор ошибок фиксированных CNN

Разбор выполняется после закрытой проверки 3 ноября 2026 года. Это объяснение
сохранённых результатов, без нового обучения, подбора порогов, проверок
значимости или изменения исхода закрытого опыта.

Основное сравнение — финально откалиброванные GroupCNN и Untied24, три
инициализации 5701, 5721 и 5757, прежние 6144 фрагмента из 24 кадров. Используются
только сохранённые классы, вероятности, маски и соответствующая разметка.

Для каждого класса вычисляются precision, recall и F1 отдельно каждой сети и
инициализации, затем усредняются три значения. Матрицы ошибок сначала
нормируются по истинному классу для каждой инициализации, затем усредняются.
Macro-F1 из объединённой матрицы трёх инициализаций не выдаётся за среднее Macro-F1.

Парные исправления — Untied ошиблась, Group верна; ухудшения — Untied верна,
Group ошиблась. Они считаются отдельно каждой инициализации и суммарно по
парам (фрагмент, инициализация). Последняя сумма содержит 18432 пары, но не
18432 независимых изображения.

В каждом направлении LR/TB класс маски имеет три состояния: 0 — путь между
границами отсутствует, 1/2 — путь есть, а нормированная геометрическая
проводимость ниже/не ниже 0,5. Подсчитываются ложные соединения 0→1/2,
пропущенные соединения 1/2→0 и перепутанные градации 1↔2. Это ошибки геометрии
бинарной маски, а не измеренные электрические неисправности.

Иллюстрации используют заранее выбранную инициализацию 5701. Для каждой из
четырёх категорий (исправление, ухудшение, обе ошиблись, обе верны) показываются
два фрагмента с минимальным SHA-256 строки
`SEM-C4-ERROR-EXAMPLES-20261103/` + category + `/` + raw-D4 hash. Изображения
не отбираются по величине выигрыша, уверенности или внешней привлекательности.
Показываются все четыре категории, включая ухудшения. Маски берутся из
сохранённого результата. Нативный SEM-фрагмент 48×48 сопоставляется с маской
12×12; обратное увеличение маски выполняется без интерполяции.

Набор происходит из одной ИС, одного слоя M2. Классы получены правилом из
SVG-масок, а не экспертной разметкой типов дефектов. Пул фрагментов уже зависит
от истинных масок через удаление однородных фрагментов и точных повторов;
последующее ранжирование отбора было слепым к классу и маске. Разбор не
доказывает причинный механизм, перенос между ИС или новизну оператора C4.
