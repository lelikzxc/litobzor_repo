# Очистка материалов текущей ВКР

Удалены неиспользуемые промежуточные веса, прогнозы и данные отвергнутых гипотез. Текущая GroupCNN, все пять пар запусков, калибровка, контрольные модели, отрицательные абляции, EDA и исходники сохранены.

Освобождено около 1,93 ГБ за вычетом компактного архива. В [ARCHIVED_EVIDENCE.zip](ARCHIVED_EVIDENCE.zip) сохранены 995 текстовых материалов и иллюстраций: код, протоколы, результаты и отчёты прежних вариантов. Полные данные и веса отвергнутых гипотез в архив не входят.

Проверено 1024 сохранённых научных файла по SHA-256; 11/11 проверок исполнения, включая реестры, EDA и CPU-инференс всех десяти состояний модели, пройдены. Один служебный SELECTION.json восстановлен из архива для проверки прежнего плана кадров. Научные файлы не изменялись. Исходные пользовательские документы, первоначальный проект, .venv и Git сохранены.
