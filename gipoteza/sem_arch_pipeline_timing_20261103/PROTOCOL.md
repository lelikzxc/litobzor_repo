# Полное время обработки фрагмента

3 ноября 2026. Описательный замер неизменённых шести моделей (Group и Untied,
seed 5701/5721/5757) из закрытого опыта с окончательной калибровкой.
Никакого обучения, выбора весов, порога или изображений по качеству нет.

Из каждого из 24 кадров EVAL берутся четыре строки с наименьшим
SHA256('SEM-C4-TIMING-20261103/'+raw_D4_sha256), затем исходный порядок EVAL.
Всего 96 одинаковых нативных фрагментов 48×48 для всех моделей. Кропы
восстанавливаются из PNG и проверяются против сохранённого входа 12×12.
PNG декодируются заранее; время чтения диска, загрузки весов, первоначальной
материализации групповых ядер, полной склейки кадра и запуска Python
не входит в задержку запроса. Подготовка этого окружения измеряется отдельно.

Измеряется полный запрос: усреднение блоков 4×4 и нормализация на CPU →
копирование входа на MPS → CNN и sigmoid → перенос вероятностей на CPU →
бинаризация при ранее зафиксированном пороге → неизменённое геометрическое
правило девяти классов на CPU. Решатель конструируется один раз до замера.

Два размера пакета: 1 и 16. Три повтора всех 96 фрагментов; порядок парных
модельных запросов внутри повторов определяется RNG 202611035. Для каждой
модели предварительно выполняются 20 CNN-запросов. Перед и после полного
запроса выполняется синхронизация MPS. Обучение на MPS одновременно не идёт.
Хранятся все длительности, медиана и p95 запросов, нормированные значения
на фрагмент и отношение медиан Group/Untied. Это описательные числа на одной
машине, без статистического заявления о превосходстве по скорости.

Два режима классового кэша: cold — пустой при начале каждого запроса
(одинаковые маски внутри пакета можно объединять); warm — заранее заполнен
всеми масками 96 выбранных фрагментов данной модели. Warm отражает повторные
маски, а не обычную обработку новых изображений. Результаты режимов разделены.
Повторное использование разобранных функций решателя не считается масочным кэшем.
Точность класса и маски в каждом запросе сверяется с архивом.

Вспомогательный профиль этапов на тех же запросах batch16/cold имеет отдельные
синхронизации и потому не подменяет основную суммарную задержку. Настройки,
код, входные PNG, веса и архивные результаты связываются SHA-256 до замера.
Предыдущие результаты не меняются. Это скорость небольшого конвейера из
изображения в геометрический класс, а не время контроля целой пластины.
