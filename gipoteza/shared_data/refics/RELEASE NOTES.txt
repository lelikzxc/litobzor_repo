USAGE:
------------------------------------------------------------------------------------------------
Every layer and node technology in REFICS has three distinct files.

1. MASK (Labelled as UID_NODE_LAYER_MAG.png)
2. LAYOUT (Labelled as UID_NODE_LAYER_MAG_gt.png)
3. SEM IMAGE (Labelled as UID_NODE_LAYER_MAG_SHOT_FOR-MEAN_FOR-STD_BCK-MEAN_BCK-STD_DT.png)

The mask and the layout images are binarized: 255/1 -> foreground and 0/0 -> background. 
The mask contains the correct label for each pixel but also contains some noise on the edges.
The layout image contains the true layout of the IC design. Please refer to the original 
papers (listed below) for details regarding usage and benchmark values.

Image generation paramters can be extracted from the file names. Use the following expansions:
UID: Unique ID
NODE: Node technology. Either 90nm or 32nm.
LAYER: Layer type. Doping (DO), Polysilicon (PO), Metal (M1) and Contacts (CO).
MAG: Magnification
SHOT: Shot noise paramter
FOR-MEAN/FOR-STD: Foreground mean and standard deviation.
BCK-MEAN/BCK-STD: Background mean and standard deviation.
DT: Simulated dwelling time.
---------------------------------------------
NOTE: There maybe several SEM images with the same UID. These images will have different image 
generation paramters but utilize the same layout. These are provided to analyse the robustness
or make robust image processing algorithms for SEM images.      
-------------------------------------------------------------------------------------------------
FOR ADDITIONAL USAGE:
-------------------------------------------------------------------------------------------------
The original layout files are given in "layout_files". Additional images can be generated using 
the provided python scripts.
1. "refics_dataset_gen_tool.py" -Generates mask, layout and SEM image. Each noise model has been 
broken down into individual functions. Every paramter can be modified. The original image 
generation functions are labelled and provided for replicability.
2. "noise_sim.py" -Simulates noise and generates noise profiles. The original simulation data, 
both raw and smoothed (moving average), are provided in "simulation_data.zip".
