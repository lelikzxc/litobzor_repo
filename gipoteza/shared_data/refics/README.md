# REFICS: авторские исходные архивы

Сохранены [simulation_data.zip](simulation_data.zip) и [tools.zip](tools.zip).
Это авторские профили моделируемого шума, топологии и инструменты
генерации синтетических SEM; данный комплект не является реальными
измерениями полупроводниковых изделий.

[Авторские примечания и CC BY 4.0](<RELEASE NOTES.txt>),
[адреса источников и SHA256](sources.json),
[состав архивов](refics_archive_inventory.json).

[Манифест прежней подвыборки](refics_manifest.json) и
[загрузчик по byte ranges](download_refics_subset.py) позволяют заново
получить исходные случаи. Распакованный subset и range-cache удалены.
Результаты отклонённого переноса находятся в историческом архиве.
