# IC SEM M2: исходная разметка и происхождение

[Авторский набор](https://doi.org/10.17617/3.HY5SYN), CC BY 4.0:
одна коммерческая ИС 128 нм, слой M2, нативный масштаб 14,65 нм/пиксель.

[labels.zip](labels.zip) содержит **все 321 оригинальные SVG-разметки**,
авторский README и лицензию, без изменения байтов. Внутренние имена
нормализованы к `dataset/labels/m2/labelNNNN.svg`.
[Соответствие исходных файлов и SHA256](SOURCE_MEMBERS.json).

46 загруженных прежде PNG занимали 442,9 MB; их локальные копии удалены.
Их исходные имена и SHA сохранены в `SOURCE_MEMBERS.json`. Для повторной
загрузки из авторского ZIP оставлены [range-reader](sem_remote_zip.py)
и [индекс архива с размерами и смещениями](sem_zip_listing.json).
Исторические метаданные загрузок находятся в `provenance/`.

Разметка задаёт материал металлизации, а не тип дефекта или измеренную
проводимость. Новые номера кадров не означают другое изделие;
у авторских кадров имеется перекрытие около 10%. Сгенерированные маски,
геометрические подвыборки и синтетические электронные отсчёты удалены.
