# C4-групповая CNN для исходной масочной задачи

SEM 12×12 → lifting 6×4 → две group-conv с dilation 2/4 → среднее ориентаций → 1×1 маска → прежнее бинарное геометрическое правило класса. Все три модели с нуля: 400 BCE + 1 600 BCE/legacy geometry.

`mask_F1` в JSON — Macro-F1 девяти классов из бинарной маски, не пиксельный F1. Отдельная метрика сегментации — IoU.

Group6: 2 671 свободный параметр, 1,528 M MAC. Основной контроль Plain12 C4: 2 749, 1,562 M MAC; полный Plain24 C4: 10 681, 6,110 M MAC. A проверяет качество при близком бюджете; B отдельно проверяет допустимую потерю к полной модели. Задержка MPS описательная, end-to-end не измерена.

Разработка на прежней VAL, все три seed: A: **PASS**; B: **PASS**. Одна и та же цель на всех трёх и новых двух seed: robust A **PASS**, robust B **PASS**. Macro-F1 group6 83.75%, Plain12 C4 82.29%, Plain24 C4 82.82%. Различных обучений здесь 18; с прежними **142**. Незавершённых запусков 0. Технические остановки и наследование весов сохранены в отчёте. Известный метод; новая loss или общая новизна не заявлены.

Независимый аудит: groupcnn_screen_s5701_metadata_recovery_27b9055b42: PASS_AUDIT (35/35); groupcnn_replicate_s5721-5757_metadata_recovery_27b9055b42: PASS_AUDIT (36/36).
