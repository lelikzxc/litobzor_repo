# Материалы оставшихся 11 гипотез

Актуальный [ранжированный список из 11 гипотез](11_gipotez_dlya_vkr.md) включает H7.1. Приоритет определяется пригодностью для ВКР и результатами, с дополнительным учётом предметной новизны. Для каждого варианта указаны формулировка, проверка, ограничения и оценка новизны.

- [Подробная постановка выбранной SEM-гипотезы](gipoteza.md): задача, датасеты, модели, формулы, результаты, три графика и пример кода.
- [Проверка SEM-гипотезы от 28 октября](sem_confirmation_20261028/REPORT.md): одинаковые дополнительные метки, новые кадры, три seed; PASS_PILOT и независимый PASS_AUDIT. Код, восстановленные данные, веса и прогнозы сохранены.
- [H7.1: формулировка и причины прежнего отклонения](H7_1.md), [полная ветка с кодом, данными и весами](h7_readout_20261025/README.md), [материалы для ВКР](h7_readout_20261025/DIPLOM_DRAFT.md).
- [Новый wafer-эксперимент: протокол](diploma_selection_20261027/NEW_MINI_PROTOCOL.md), [результаты](diploma_selection_20261027/wafer_analysis/RESULT.json), [независимая проверка](diploma_selection_20261027/wafer_analysis/INDEPENDENT_AUDIT.json). Код, входные данные, все веса и прогнозы лежат рядом.
- [Исторические материалы SEM/EP2](retained_evidence_20261027/README.md): отчёты, протоколы, исходный код, SHA и отрицательные контроли. Ранние крупные данные и веса были удалены прежними очистками; это не полный готовый пакет воспроизведения.
- [Оставшиеся общие данные](shared_data/README.md), [литература](literatura_20261019.md), [исходный исследовательский контекст](../full_wafer_research_context_updated.md).
