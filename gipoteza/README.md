# Сегментация и классификация геометрии металлизации

Текущая работа для бакалаврской ВКР — GroupCNN для SEM-сегментации металла и последующей классификации девяти геометрических состояний маски.

[Материалы для научного руководителя: PDF](materialy_nauchnomu_rukovoditelyu/output/pdf/issledovanie_metallizatsii.pdf) и [редактируемый текст](materialy_nauchnomu_rukovoditelyu/issledovanie_metallizatsii.md): задача, реальные изображения и маски, модель и результаты.

[Понятный рассказ для встречи с научным руководителем](podgotovka_k_vstreche_20261105.md): гипотеза, данные, устройство модели, последовательность проверок, результаты и ответы на вопросы.

Начать с [общего итогового отчёта](sem_arch_final_validation_20261103/REPORT.md): пять пар запусков, Macro-F1 75,95% против 73,20% у свободной CNN24, прирост +2,75 п.п. при одинаковых MAC и обучающем надзоре. Данные относятся к одному слою одной ИС; классы вычислены из SVG-масок.
