# Закрытое подтверждение C4-групповой CNN

Первичный исход: **PASS_CONFIRMATION**. A_matched_quality: подтверждена; B_full_efficiency: не подтверждена. Независимые аудиты данных и результата PASS.

16 новых полей одной ИС, 4 096 фрагментов, 18 фиксированных моделей. Новых fit 0; прежних уникальных fit 142. `mask_F1` означает Macro-F1 девяти масочно-геометрических классов; IoU — сегментация.

A проверяет качество к узкой C4 при близких параметрах/MAC; B отдельно проверяет допустимую потерю к полной C4 при MAC 0,25. 10 000 парных crossed-bootstrap повторов по seed/кадрам, интервалы 97,5%. Вторичные пороги не заменяют первичный исход. End-to-end latency не измерена.
