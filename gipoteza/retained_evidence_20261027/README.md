# Исторические материалы оставшихся гипотез

Сохранены результаты SEM-регуляризации, классификации через маску, SEM-ячеек и EP2-Core, а также отрицательные контроли и расширения, ограничивающие их выводы. Это исторические снимки, не новые запуски.

- [Отобранные отчёты, протоколы и результаты](SELECTED_RECORDS.json): точный текст, исходные пути, SHA и SHA полных архивов до очистки.
- [Исторический код](SELECTED_SOURCES.zip), [его манифест](SOURCE_MANIFEST.json): только относящиеся к этим опытам исходники и локальные зависимости. Имена путей внутри ZIP сохранены; сторонний код не исполнялся при отборе.
- [Защищённые файлы H7.1](H7_PROTECTED.json): исходный манифест 292 файлов, трёх ссылок и двух общих документов. Саму ветку H7.1 не изменяли.

Крупные данные и веса этих ранних SEM/EP2 опытов были удалены предыдущими очистками. ZIP не заменяет их и не обещает полный запуск без восстановления данных. Для нового wafer-стенда и H7.1 данные/веса существуют.

`diploma_selection_20261027/recover_evidence.py` и `EVIDENCE_AUDIT.json` — точные исторические следы одноразового извлечения из прежних полных архивов. Эти архивы удалены как содержащие посторонние ветки; повторять старый helper без них нельзя. Для чтения выбранных материалов используйте SELECTED_RECORDS.json и уже извлечённую папку sources/. Старые frozen manifests не переписывались.
