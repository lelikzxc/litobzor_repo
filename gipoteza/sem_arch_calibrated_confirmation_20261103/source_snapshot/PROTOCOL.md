# Закрытое подтверждение CNN с зафиксированной калибровкой

3 ноября 2026 года. Протокол установлен до загрузки новых изображений.
Цель — проверить архитектурный эффект GroupCNN относительно свободной Untied24
при одинаковых ширине, MAC, вспомогательном обучении и процедуре калибровки.
Новых обучений CNN и обновлений весов нет. Ранее полученные результаты
сохраняются отдельно; текущая процедура их не переписывает.

## Фиксированные модели и предметная область

GroupCNN, Untied24 single и Plain12 C4, бюджет 27 полных масок,
seed 5701/5721/5757: всего девять конечных состояний. Везде прежние
1152 weak-метки и общий geometry_loss. У Group и Untied одинаковые
24 фактических канала и 1527552 MAC, но 2671 и 10681 свободный параметр.
Их начальная функция совпадала до обучения; это проверено прежним независимым
аудитом и повторно связывается хешами. Узкая Plain12 C4 имеет 2749 параметров,
1562112 MAC и четырёхвидовое усреднение; она является дополнительным контролем.

По SEM-фрагменту M2 одной ИС сеть восстанавливает маску металла; неизменённое
бинарное геометрическое правило переводит маску в один из девяти классов.
Это вычисленные из SVG-масок геометрические состояния, а не экспертные
типы производственных дефектов или электрические измерения.

## Окончательная калибровка до новых кадров

Используются только прежние 40 кадров DEV и их замороженные вероятности.
Из них выбираются первые 32 по SHA256
('SEM-C4-FINAL-CALIB-FRAME-20261103/'+decimal_frame_id), без учёта меток,
оценок или порогов отдельных прежних fold. На каждом выбранном кадре берутся
те же 16 фрагментов по SHA256('SEM-C4-CALIB-ROW-20261103/'+raw_D4_sha256),
что предусмотрены прежней процедурой. Всего 512 классовых меток, одни и те же
для девяти состояний. Полные маски в выборе порога не используются.

Каждому состоянию выбирается один порог из 81 значения 0.10…0.90:
максимум Macro-F1 девяти классов на этих 512 метках, затем ближайший к 0.5,
затем меньший. Расстояния сравниваются в целых сотых. Сохраняются индексы,
кадры, покрытие классов, все 81 оценки и итоговые пороги. Классы не добираются
и набор не заменяется по качеству. Повторного выбора на новых данных нет.

Сначала preflight на 17 старых VAL-примерах: все девять моделей через тот же
inference-код, batch 16+1, вероятности с допуском 1e-5, маски/классы при новом
окончательном пороге и при 0.5 сверяются с архивными массивами. Проверяются
статистика на синтетических данных и независимая реконструкция калибровки.
Затем хешами фиксируются модели, пороги, источники, код, конфигурация и план
кадров. Независимый аудит проходит до загрузки новых изображений.

## Новый набор

Из 321 M2-кадра исключаются 134 ID из прежних планов и данных: 110 из
плана последней проверки плюс её 24 кадра. Оставшиеся ранжируются по
SHA256('SEM-C4-CALIB-CONFIRM-20261103/'+decimal_id); первые 24 фиксируются
до скачивания. Замены кадров по результатам не допускаются.

Прежняя подготовка: отступ 512 нативных пикселей, уменьшение 4×4,
фрагмент 12×12 с шагом 6, маска большинства ≥0.5. Удаляются однородные
целевые маски и точные D4-повторы масок/исходных интенсивностей по восьми
прежним манифестам и внутри нового набора. Маски участвуют в этой фильтрации
кандидатов; последующее ранжирование кандидатов маску и класс не использует.
Независимая физическая регистрация координат полей съёмки не заявляется.

Для оценки выбираются первые 256 фрагментов каждого кадра по
SHA256('SEM-C4-CALIB-EVAL-20261103/'+raw_D4_sha256). Всего 6144 фрагмента.
Требуется ≥8 примеров и ≥3 разных кадров каждого класса. Если покрытие
не проходит, фиксируется недостаточность выборки без замены/пересэмплирования.
Полный TEST и выбранный EVAL сохраняются; оставшиеся фрагменты тех же кадров
не являются ещё одним независимым тестом. Аудит данных обязателен до вывода CNN.

## Основная составная гипотеза

Основное сравнение — только Group−Untied при окончательных порогах.
Для подтверждения должны одновременно пройти:

- наблюдаемый средний ΔMacro-F1 ≥+0.5 п.п.;
- нижняя граница 97.5%-интервала ΔMacro-F1 строго >0;
- средний покадровый ΔAP сегментации строго >0;
- нижняя граница 97.5%-интервала ΔAP строго >0;
- ΔMacro-F1 каждого seed ≥−1 п.п.;
- средний ΔIoU ≥−0.2 п.п.;
- MAC Group и Untied совпадают; предыдущий допуск разработки и аудиты пройдены.

AP — non-interpolated average precision, отдельно по пикселям каждого кадра,
затем среднее по кадрам и seed. Это ранжирование пикселей до бинаризации,
а не трапециевидная площадь и не Macro-F1 девяти классов. Macro-F1 считается
по всем фрагментам отдельно для каждого seed, затем усредняется. Это среднее
индивидуальных метрик, не ансамбль; confusion разных seed перед F1 не сливаются.
IoU — среднее по фрагментам.

Для двух исходов AP/F1: 10000 общих парных crossed-bootstrap повторов,
seed 202611034. В каждом повторе выбираются с возвращением три seed и 24 кадра;
одни индексы используются обеими моделями и обоими исходами. Для F1 сначала
суммируются confusion выбранных кадров отдельно по выбранному seed, вычисляется
Macro-F1, затем среднее seed. Для AP усредняются выбранные покадровые AP по
выбранным seed/кадрам. Квантили [0.0125,0.9875] задают центральные 97.5%-интервалы,
консервативную поправку Бонферрони для двух исходов при номинальном семейном 95%.

Интервалы приблизительные, при трёх инициализациях одной ИС. Фрагменты и пиксели
не считаются независимыми повторениями. Порог +0.5 п.п. относится к наблюдаемой
точечной разности; требование нижней границы >0 не доказывает популяционный
минимальный прирост ≥0.5 п.п. Все условия применяются одновременно.

## Дополнительные результаты и границы

Plain12 C4, общий порог 0.5 и сравнения с ним описательные: без дополнительных
интервалов, p-value, тестов превосходства и возможности заменить основной исход.
Для всех девяти состояний приводятся AP/F1/IoU, зафиксированные пороги и seed.
Порог 0.5 не является дополнительным условием текущей гипотезы: устойчивость
к нему ранее не прошла и сохранена как отдельный исторический результат.
Здесь проверяется явно ограниченный метод с зафиксированной процедурой калибровки.

Успех относится к новым кадрам той же ИС, общему вспомогательному обучению и
указанному бюджету калибровки. Перенос на другие изделия, универсальная польза
при любых лоссах и мировой приоритет известной C4-конструкции не устанавливаются.
Любой отрицательный или неопределённый результат сохраняется. Новые кадры
не используются для последующего подбора с сохранением названия «закрытые».
